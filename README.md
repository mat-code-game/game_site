# Mes jeux Scratch 🎮

Bienvenue sur la page **Mes jeux Scratch**, un petit site web que j’ai créé pour regrouper et présenter mes projets Scratch !

## 🌐 Démo en ligne

👉 [Voir la page en ligne](https://mat-code-game.github.io/game_site/)  

ou lien court : [https://urlr.me/jy9vHw](https://urlr.me/jy9vHw)

## 🎯 Description

Ce projet affiche mes créations Scratch directement sur une page web simple et propre.  
Chaque jeu est intégré avec une iframe afin que tu puisses y jouer depuis la page, ou cliquer pour ouvrir le jeu sur le site officiel de Scratch.

Les projets inclus :

- 🌀 **Balquive 2** — un jeu de plateformes amusant.  
- 🐱 **Le chat et les souris** — un mini-jeu de poursuite entre animaux.  
- ⚾ **Baseball sauteur** — un challenge sportif et original.  
- 💬 **BD pour le collège** — une bande dessinée interactive réalisée pour un projet scolaire.

## 🧠 Technologies utilisées

- **HTML5** pour la structure de la page.  
- **CSS3** pour le style et la mise en page.  
- **Scratch Embeds** pour l’intégration directe des jeux en ligne.

## 🧩 Améliorations possibles

- Ajouter un logo ou une bannière en haut de la page.  
- Créer un menu de navigation avec plus de jeux.  
- Adapter le design aux téléphones (responsive design).
